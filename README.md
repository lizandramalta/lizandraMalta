# Olá, eu sou a Liz! 👋

Sou desenvolvedora de software com foco em **desenvolvimento frontend web e mobile**, atuando principalmente com **React, React Native, TypeScript, Swift e SwiftUI**.

Atualmente, participo do **Apple Developer Academy**, onde trabalho no desenvolvimento de aplicações para os ecossistemas iOS e macOS em equipes multidisciplinares. Ao longo dessa experiência, venho participando de diferentes etapas da criação de produtos digitais, desde a definição da solução e estruturação da arquitetura até a implementação, integração com APIs e evolução das funcionalidades.

Gosto de construir aplicações bem organizadas, com interfaces intuitivas, código de fácil manutenção e soluções que façam sentido para quem utiliza o produto.

## 📚 Projetos de estudo

Projetos desenvolvidos durante formações e desafios práticos, com foco no aprofundamento dos meus conhecimentos em React Native, TypeScript e desenvolvimento mobile.

### Marketspace

Marketplace mobile que permite publicar produtos, visualizar anúncios, aplicar filtros de busca e entrar em contato com vendedores pelo WhatsApp.

Implementei os fluxos de cadastro e autenticação, gerenciamento de sessão com JWT e refresh token, criação e edição de anúncios, upload de múltiplas imagens, formulários com validação e filtros combinados.

A aplicação mobile foi integrada a uma API disponibilizada pela Rocketseat.

**Tecnologias:** React Native, Expo, TypeScript, Axios, React Navigation, Context API, AsyncStorage, React Hook Form e Yup.

[📂 Ver repositório](https://github.com/lizandramalta/marketspace)

---

### Ignite Gym

Aplicativo mobile para acompanhamento de exercícios, permitindo consultar treinos, registrar atividades concluídas, acompanhar o histórico e atualizar informações do perfil.

Implementei os fluxos autenticados e não autenticados, integração com API REST, autenticação com JWT e refresh token, persistência da sessão, filtros por grupos musculares, histórico de exercícios e atualização de perfil com upload de imagem.

A API utilizada no projeto foi disponibilizada pela Rocketseat.

**Tecnologias:** React Native, Expo, TypeScript, Axios, React Navigation, Context API, AsyncStorage, React Hook Form, Yup e Gluestack UI.

[📂 Ver repositório](https://github.com/lizandramalta/ignitegym)

---

### Nearby

Aplicativo mobile de clube de benefícios que permite encontrar estabelecimentos próximos e resgatar cupons por meio da leitura de QR Codes.

Implementei a exibição de estabelecimentos em mapas, navegação com rotas dinâmicas, integração com API, acesso à câmera, leitura de QR Code e apresentação das informações e benefícios de cada local.

A API utilizada no projeto foi disponibilizada pela Rocketseat durante um evento prático.

**Tecnologias:** React Native, Expo, TypeScript, Expo Router, React Native Maps, Expo Camera e Axios.

[📂 Ver repositório](https://github.com/lizandramalta/nearby)

---

### Daily Diet

Aplicativo mobile para cadastro e acompanhamento de refeições, com funcionamento offline e armazenamento local dos dados.

Implementei o CRUD de refeições, agrupamento dos registros por data e cálculo de métricas, como percentual de refeições dentro da dieta e maior sequência de refeições dentro do objetivo.

**Tecnologias:** React Native, Expo, TypeScript, AsyncStorage, React Navigation e Styled Components.

[📂 Ver repositório](https://github.com/lizandramalta/daily-diet-app)
